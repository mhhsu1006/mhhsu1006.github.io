# Quality Gates｜交付前必查

這是**可操作的發布門檻**，不是「請仔細檢查」等模糊要求。每章檢查後，再做一次跨章檢查。若使用者只要求簡短答覆，也應在內部執行相關檢查，不必把整張表貼給學生。

## A. 來源與範圍

- [ ] 已逐份讀取可用的原始課件，包含圖表和題目；無法讀取者已註明。
- [ ] 核心定義、公式和考點能指回**真實**文件／頁次，沒捏造頁碼或考試比重。
- [ ] 課件內容、額外權威資料、教學示例、不確定推測互相區分。
- [ ] 若課件疑似錯誤或與其他來源衝突，有列出衝突及其影響，未強行一致化。

## B. 邏輯與模型

- [ ] 同一術語在全篇指同一事物；跨模型同名但定義不同時有顯式說明。
- [ ] 各公式中的符號、單位和適用條件首次使用前已定義。
- [ ] 每個「因為／所以」有可檢查的中間推理；沒有把描述性觀察冒充因果規律。
- [ ] 切換假設（其他條件不變、無現金漏損、線性、完全競爭等）時有明示。
- [ ] 圖的坐標軸、曲線移動、變量比較與文字解釋一致。
- [ ] 前一章結論未在後一章被無解釋地否定。

## C. 解題核驗

- [ ] 例題重新獨立求解，不是照自己前一次輸出檢查。
- [ ] 數值、步驟、單位、捨入、條件和最終結論一致。
- [ ] 例題有說明「為何用這個公式」，而不只列式。
- [ ] 每個核心學習目標至少有一個可答題／可口頭解釋的檢查點；答案足以自行核對。

## D. 初學者教學檢查

- [ ] 無未定義就使用的必要專業詞，或在使用處提供可理解的短解釋。
- [ ] 教學順序依先備關係安排，沒有循環解釋。
- [ ] 直覺敘述不犧牲正確性，若為簡化模型有清楚的前提。
- [ ] 抽象句可還原成具體對象、變量、行為及理由；否則刪改。
- [ ] 學生在不額外搜尋資料的條件下，能沿例題逐步復現解法（作為設計檢查，不宣稱已做真實學生測試）。

## E. 錯誤分級與處置

| 級別 | 例子 | 處置 |
|---|---|---|
| Blocker（阻斷） | 公式錯、例題錯、來源重大誤讀、模型假設互相矛盾、錯誤因果 | 暫不交付該部分；改正後重審受影響章節 |
| Major（主要） | 關鍵先備概念遺漏、概念跳躍造成無法理解、核心考點缺失 | 補教學橋接／補來源後重檢 |
| Minor（次要） | 少量累贅文字、格式不整齊、非關鍵用詞不一致 | 交付前優先修正；若有限制可明示 |

**通過條件**：在已取得足夠來源的範圍內，Blocker=0、Major=0；每個核心概念有可追溯依據、解釋鏈和至少一個可驗證學習檢查。若資料缺漏，僅對**可核實部分**聲稱完成，不宣稱完整覆蓋。

## 不可做的事

- 不得先寫錯、再在末尾附「注意」來替代修正文內錯誤。
- 不得把幻覺出來的老師要求、分數配比、考題趨勢當事實。
- 不得以「學生看不懂是因為基礎差」取代內容檢討。
- 不得以清單打勾作為外部實測學生理解的證據。

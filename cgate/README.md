# cgate project website

Live site: https://mhhsu1006.github.io/cgate/

Self-contained static website. GitHub Pages serves `index.html` and `assets/`.

To edit, change `tools/index.src.html`, `tools/partials/`, or `assets/`. Run `npm ci` (or `npm install` on the first build) and `npm run build` in `tools/`, then commit both source and generated `index.html`.
